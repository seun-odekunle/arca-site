# arcaholdingsllc.com

The website of Arca Holdings LLC: a home page and a privacy page.

Plain HTML and CSS, no scripts, no build step. Light and dark follow the visitor's device setting.
Fonts (Schibsted Grotesk, SIL Open Font License, see `fonts/OFL.txt`) and images are served from the site itself.

Hosted on GitHub Pages from the `main` branch.
